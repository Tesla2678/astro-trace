# 星轨 AstroTrace

本地排盘应用（内测版）。西洋占星、八字命理、紫微斗数、奇门遁甲在本机排盘，提示词在本机拼装。

- **数据不出手机**：案主资料、命盘结果、复制记录全部只存在本机。用邮箱账号登录时，服务器只保存账号与登录信息。
- **不内置大语言模型**：应用负责排盘与拼装，结果由你复制到任意大模型去解读。
- **离线星历**：本命盘与推运按内置天文星历计算，出生地行政区划与经纬度随包离线。

## 下载

内测版暂未上架应用商店，请从项目主页的下载按钮取安卓安装包：

- 主页：`index.html`
- 安装包：`releases/latest` 里的 `astro-trace.apk`

安装时需允许「安装未知来源应用」；内测包使用调试证书签名，覆盖安装前请先卸载旧版本。

## 功能

| 模块 | 说明 |
| --- | --- |
| 西洋占星 | 本命盘、推运、合盘、关系评分 |
| 八字命理 | 四柱排盘、大运流年 |
| 紫微斗数 | 十二宫盘、亮度、旺衰 |
| 奇门遁甲 | 时家奇门盘 |
| 提示词 | 按体系拼装，可直接复制 |

## 备份与迁移

「设置 → 本地数据 → 导出备份」会生成一份 JSON 备份。换设备后，在「新建案主」页下方的「导入案主信息」里选这个备份文件即可合并回来：只导入案主资料，命盘与推运由应用自己重算，本机已有的案主不受影响。

## 隐私

| 数据 | 去向 |
| --- | --- |
| 案主资料 | 只在本机 |
| 命盘与推运结果 | 只在本机 |
| 复制记录 | 只在本机 |
| 账号与登录信息 | 账号服务（仅此一项） |

应用不采集任何分析数据。备份文件里含出生日期与地点，请只保存在自己的设备上。
