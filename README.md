# 星轨 AstroTrace

本地排盘应用（内测版）。西洋占星、八字命理、紫微斗数、奇门遁甲在本机排盘，提示词在本机拼装。

- **数据不出手机**：案主资料、命盘结果、复制记录全部只存在本机。用邮箱账号登录时，服务器只保存账号与登录信息。
- **不内置大语言模型**：应用负责排盘与拼装，结果由你复制到任意大模型去解读。
- **离线星历**：本命盘与推运按内置天文星历计算，出生地行政区划与经纬度随包离线。
- **提示词带专业规则推算**：提示词里不只给盘面原始数据，还给按专业规则算好的中间结论（判定名、依据、置信度、口径一并写明），模型只需解读、不必重新推演。数据覆盖不到的地方会写「数据未覆盖，无法判定」，不用含糊话搪塞。

## 下载

内测版暂未上架应用商店，请从项目主页的下载按钮取安卓安装包：

- 主页：`index.html`
- 安装包：`releases/latest` 里的 `astro-trace.apk`

安装时需允许「安装未知来源应用」；内测包使用调试证书签名，覆盖安装前请先卸载旧版本。

## 功能

| 模块 | 说明 |
| --- | --- |
| 西洋占星 | 本命盘、推运、合盘、关系评分 |
| 八字命理 | 四柱排盘、大运流年；运势卡带运限推算 |
| 紫微斗数 | 十二宫盘、亮度、旺衰、大限流年；运势卡带运限推算 |
| 奇门遁甲 | 时家奇门盘、运限落宫；运势卡带运限推算 |
| 提示词 | 按体系拼装，可直接复制 |
| 专业规则推算 | 提示词里带判定结论、依据与口径；本命与运势分开成层，运势按「运限必须挂本命」先判承载再给事实 |
| 分享给 AI | 点一下拉起手机自带的分享面板，里面列出本机装好的 AI 应用（千问 / ChatGPT / DeepSeek 等），选一个就打开并把整段提示词带进它的输入框 |
| 版本更新 | 「设置 → 更多 → 版本更新」里点「检查更新」，有新版就直接在应用里下载并交给系统安装器完成覆盖升级，不用再自己去网页下载、手动安装 |
| 备份导入 | 首页与案主列表的空状态里都有「导入案主数据」；整库恢复也改成直接选手机里的备份文件，不用粘贴文本 |

## 备份与迁移

「设置 → 本地数据 → 导出备份」会生成一份 JSON 备份。换设备后有三条路都能导回来：首页空态的「导入案主数据」、案主列表空态的「导入案主数据」、以及「新建案主」页下方的「导入案主信息」——都只需要在手机里选中那个备份文件。只导入案主资料，命盘与推运由应用自己重算，本机已有的案主不受影响。

## 隐私

| 数据 | 去向 |
| --- | --- |
| 案主资料 | 只在本机 |
| 命盘与推运结果 | 只在本机 |
| 复制记录 | 只在本机 |
| 账号与登录信息 | 账号服务（仅此一项） |

应用不采集任何分析数据。备份文件里含出生日期与地点，请只保存在自己的设备上。

唯一的对外请求是「版本更新」：你主动点「检查更新」时，应用向发布仓库问一句最新版本号，那次请求里不含任何本机数据。
